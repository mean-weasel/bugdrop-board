## Test Harness Correction

The first post-rotation browser run created Issue #6 and synchronized the item, but timed out before
clicking the upvote. The trace showed the test was waiting for the obsolete accessible name
`Upvote 0`; the widget's current accessibility contract names the control with its item title and
upvote count.

`e2e/staging-board-widget.spec.ts` now uses the same complete accessible names and `aria-pressed`
assertions as the local two-viewer test. This makes the staging proof exercise the real accessible
control contract instead of matching visible button text.
