# BugDrop Board v0.2.0 Customization Release Prep

Status: published, tagged, released, and independently install-smoked.

BugDrop Board `v0.2.0` is the planned release for the embedded widget customization contract. It
promotes the already-merged and production-dogfooded `data-config-selector` support for host-owned
copy, layout, density, and theme configuration.

## Release Intent

- npm package: `@mean-weasel/bugdrop-board@0.2.0`
- Release reason: public embedded-widget customization contract.
- Compatibility: backward-compatible with existing script installs that use `data-board-id`,
  `data-api-url`, `data-token-endpoint`, `data-poll-interval`, `data-color`, `data-layout`,
  `data-density`, or `data-mount-selector`.
- Publish gate: satisfied. The version PR merged, the main package dry-run passed, and the
  maintainer explicitly approved `Package Widget` with `dry_run=false` and `npm_tag=latest`.

## Included Changes

- Optional `data-config-selector` pointing to an `application/json` config element.
- Configurable copy for headings, form labels/placeholders, submit/loading/empty/error/retry text,
  issue prefix, and upvote/upvoted labels.
- Configurable layout and density through stable values.
- Configurable theme tokens for colors, typography, spacing, radii, fields, buttons, upvotes,
  borders, shadows, and focus treatment.
- Stable host-level CSS custom properties while keeping Shadow DOM isolation.
