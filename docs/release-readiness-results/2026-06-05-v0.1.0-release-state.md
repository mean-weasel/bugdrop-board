# BugDrop Board v0.1.0 Release State

## Summary

Status: consolidated after production dogfood, production deploy workflow proof, and package
workflow dry-run proof.

BugDrop Board `v0.1.0` is the first public self-hostable embedded board release. The npm package is
published, the production Worker is live, the real `bugdrop.dev` embedded dogfood flow has passed,
and the GitHub Actions promotion path now proves browser CORS for authenticated board reads.
