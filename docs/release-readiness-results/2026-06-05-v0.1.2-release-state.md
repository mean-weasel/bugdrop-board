# BugDrop Board v0.1.2 Release State

Status: published, tagged, released, and production dogfooded.

BugDrop Board `v0.1.2` is a patch release for inline embedded-widget mount targets. It adds
`data-mount-selector` support so self-hosters and dogfood hosts can render the feedback board inside
an explicit in-app container instead of relying on the default script-adjacent or body append path.

## Included Changes

- Widget mount helper for `data-mount-selector`.
- Default script-adjacent host insertion when no selector is configured.
- Head-script fallback that still appends to `document.body`.
- Missing-selector error path with a clear configuration message.
- README embed/install contract updates for inline host containers.
- Dummy host fixture and e2e coverage for inline widget rendering.
